# sanjeevvarmaragula.com

Personal portfolio of Sanjeev Varma Ragula, published with GitHub Pages at
https://sanjeevvarmaragula.com.

Plain HTML, CSS and JavaScript with no build step: edit `index.html`, `styles.css` or `main.js`
and push to `main`. To preview locally, run `python -m http.server 8080` in this folder and open
http://localhost:8080.
